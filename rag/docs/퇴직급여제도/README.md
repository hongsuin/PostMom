## 주요 질문 유형
- 퇴직금 지급 요건 (1년 이상 계속근로, 주 15시간 이상)
- 퇴직금 계산 방법 (30일분 평균임금 × 계속근로연수)
- 학원 강사의 근로자 여부 판단 (4대보험 가입, 지휘·감독 여부)
- 계약직·시간강사의 퇴직급여 수급 가능 여부
- 퇴직연금(DB형/DC형) 도입 여부 및 차이
- 퇴직금 중간정산 허용 요건 (무주택 주택 구입 등)
- 퇴직금 지급 시한 (퇴직 후 14일 이내) 및 지연이자
- 4대보험 미가입 강사의 퇴직금 청구 가능 여부
- 폐업 시 퇴직금 처리 방법

## 카테고리 간 연관관계
- **임금**: 평균임금 산정 기준 공유 (근로기준법 §2)
- **기간제및단시간근로자**: 기간제법상 차별 금지와 퇴직급여 동일 적용 의무
- **실업급여**: 퇴직금과 실업급여는 별개 권리 (동시 수급 가능)
