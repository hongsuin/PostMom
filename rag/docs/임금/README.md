## 주요 질문 유형
- 임금 미지급 및 체불 처리 방법
- 최저임금 적용 및 산입 범위
- 평균임금·통상임금 계산 기준
- 임금 지급일, 지급 방법 (직접·통화 지급 원칙)
- 임금 공제 가능 항목 (세금, 4대보험 등)
- 임금채권 시효 및 체불임금 구제 절차
- 수습기간 중 임금 감액 가능 여부
- 연장·야간·휴일 근로 가산수당 계산

## 카테고리 간 연관관계
- **퇴직급여제도**: 평균임금 산정 방식 공유 (근로기준법)
- **실업급여**: 이직 전 평균임금이 급여 산정 기준
- **기간제및단시간근로자**: 단시간근로자 임금 비례 원칙 적용
