# 학원 노무 RAG 문서 인덱스

## 카테고리 구성

각 카테고리는 다음 두 종류의 문서로 구성됩니다:
- **`[pdf]*.pdf`** — 해당 주제의 주요 Q&A 답변 문서 (법령 기반으로 작성)
- **법령 PDF** — 답변 문서에서 참조하는 실제 법령 원문

## RAG 검색 전략

### 문서 유형별 우선순위
1. `[pdf]` 파일: 학원 현장에 맞게 정리된 Q&A → **1차 답변 근거**
2. 법령 원문 파일: 구체적 조문 확인 필요 시 → **2차 근거 (조문 인용)**

### 카테고리 간 공통 참조 법령
- **근로기준법**: 임금, 퇴직급여제도, 기간제및단시간근로자 공통 참조

- **남녀고용평등법**: 임금(동일임금), 기간제및단시간근로자(육아휴직) 공통 참조
